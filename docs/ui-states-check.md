# Чекліст станів екранів

Перевірка, що кожен екран коректно показує стани «дані / порожньо / приватний / помилка».

**Як перевіряли.** Застосунок у фейковому режимі (`"UseFakes": true`), для кожного екрана окремий запуск; стан перемикався Debug-панелею внизу екрана, а видимий текст читався через UI Automation. Окремо стани на рівні сервісів покриті тестами `FakeStatesTests` (`SteamTracker.Tests/UI`). Дата перевірки: 12.11.2026.

## Що ще перевірено на матчмейкері

- Невалідний ввід («Невідомий гравець», неіснуючий SteamID) потрапляє в червоний банер, а не валить запит.
- Дублікати, порожні рядки й сам користувач у вводі ігноруються.
- Більше 8 учасників разом із користувачем: помилка «Забагато учасників».
- Один відкритий і один прихований профіль: «Недостатньо відкритих бібліотек», а не падіння.

## Примітки

- Фейкові сервіси зареєстровані як singleton, тож режим, обраний на одному екрані (наприклад «Помилка» в радарі), лишається для інших екранів, які користуються тим самим фейком, до перезапуску. Для Debug це очікувано, але перевіряти екрани краще окремими запусками.
- Головна не має перемикача станів: її картки беруть дані з тих самих фейків бібліотеки та друзів, тож стани перевіряються на їхніх екранах.

## Знайдено й виправлено під час перевірки (#99)

- «11 досягнень» показувалось як «11 досягнення» (і так для 111, 211…).
- Час «59,5 хв» на екрані порівняння показувався як «60 хв» замість «1 год».
- Нік, що починається з емодзі, давав розрізаний символ замість ініціалу в аватарі.
- `IconUrlConverter` падав або читав диск на `file://` та інших не-http посиланнях, тепер приймає лише http(s).
