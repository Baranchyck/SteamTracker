# Steam Tracker — специфікація MVP

## 1. Технологічний стек

| Шар | Технологія |
|---|---|
| Застосунок | C#, .NET, настільний застосунок (Windows) |
| Графічний інтерфейс | WPF (XAML) |
| Робота з даними | ADO.NET (Npgsql) |
| База даних | PostgreSQL |
| Виклики Steam Web API | `HttpClient` |
| Контроль версій | Git + GitHub, робота в гілках, злиття через pull request |
| Тестування | MSTest / xUnit / NUnit |
| CI | GitHub Actions — збірка та тести на кожен push/PR |

Критерій відбору фіч у MVP:
1. Дані отримуються одним-двома викликами офіційного Steam Web API.
2. Немає залежності від приватної фінансової інформації користувача.
3. Не потрібен фоновий процес з накопиченням історії у часі.

## 2. Функціональні модулі

### 2.1 Авторизація через Steam

Steam OpenID: застосунок відкриває системний браузер на сторінці логіну Steam, локальний `HttpListener` на `localhost` приймає перенаправлення з підтвердженням. Отриманий SteamID64 зберігається локально для наступних запусків.

Базовий профіль — `ISteamUser/GetPlayerSummaries` (нікнейм, аватар, рівень приватності). Приватний профіль обробляється як окремий стан інтерфейсу, не як помилка.

Ключ Steam Web API не зберігається у відкритому коді — виноситься в конфігурацію поза контролем версій.

### 2.2 Планувальник досягнень

- `GetOwnedGames` — список ігор користувача.
- `GetPlayerAchievements` — закриті ачівки для обраної гри.
- `GetGlobalAchievementPercentagesForApp` — глобальний % отримання по кожній ачівці.
- Незакриті ачівки сортуються за глобальним відсотком (найбільш масові — першими).
- Розрахунок, скільки ачівок потрібно закрити, щоб підняти % проходження гри на N пунктів.

Глобальний % не є мірою складності ачівки — в інтерфейсі це позначається окремо.

### 2.3 Порівняння часу гри з друзями

- `GetFriendList` — список друзів.
- `GetOwnedGames` по кожному другу (паралельно, обмежено через `SemaphoreSlim`) — `playtime_forever` для обраної гри.
- Лідерборд, позиція користувача, % від середнього, список друзів без цієї гри.
- `playtime_2weeks` — окремий індикатор поточної активності.

### 2.4 Друзі-радар

- `GetFriendList` + `GetPlayerSummaries` (batch до 100 SteamID) — `personastate`, `gameid`, `gameextrainfo`.
- Фільтр «вільні зараз» (online / in-game, без offline і away).

### 2.5 Co-op Matchmaker

- Список SteamID → `GetOwnedGames` по кожному → перетин бібліотек.
- Сортування спільних ігор за середнім playtime групи.
- Фільтр підтримки кооп-режиму не входить у MVP — потребує тегів гри з неофіційного `appdetails`.

### 2.6 Використання бібліотеки

- `GetOwnedGames` — playtime по всій бібліотеці, виявлення ігор з `playtime_forever` близьким до нуля.
- Розрахунок вартості за годину не входить у MVP: залежить від неофіційного `appdetails` і поточної (не історичної) ціни покупки.

### 2.7 Спільний UI/UX

Єдина навігація між модулями, асинхронні запити з індикатором завантаження, окремі стани для помилок API та приватних профілів.

### 2.8 Тестування, збирання, документація

Unit-тести на сервісний шар (Steam API, доступ до даних). Інтеграційні тести за потреби. Збірка та тести — через GitHub Actions на кожен pull request. README з інструкцією збирання й запуску.

## 3. Нефункціональні вимоги

- **Продуктивність.** Мережеві виклики асинхронні, інтерфейс не блокується.
- **Надійність.** Недоступність API, відсутність мережі чи приватний профіль обробляються без аварійного завершення застосунку.
- **Безпека.** Ключ API поза репозиторієм; вхідні дані (SteamID у Co-op Matchmaker) валідуються.
- **Зручність використання.** Одне головне вікно, навігація між модулями без перезапуску.
- **Портованість.** Цільова платформа — Windows.
- **Тестованість.** Логіка роботи з API та даними відокремлена від коду UI.

## 4. Додаткові фічі (backlog)

| Фіча | Опис | Ендпоінти |
|---|---|---|
| Бейдж «Ветеран/Новачок» | За датою реєстрації акаунту | `GetPlayerSummaries` (`timecreated`) |
| Ігри без жодного запуску | Фільтр `playtime_forever == 0` | `GetOwnedGames` |
| Найстаріша непройдена гра | Сортування за `rtime_last_played` | `GetOwnedGames` |
| Хто з друзів найдовше в Steam | Сортування друзів за датою реєстрації | `GetFriendList`, `GetPlayerSummaries` |
| Річниця акаунту | «Х років у Steam» | `GetPlayerSummaries` (`timecreated`) |
| Швидкий запуск гри | `steam://run/{appid}` | — |

## 5. Технічні ризики

- **Приватність профілів.** `GetOwnedGames` / `GetPlayerAchievements` повертають порожні дані при закритих Game Details — обробляється як окремий стан, не як помилка чи нуль.
- **Rate limits.** ~100 000 запитів/добу на ключ. Паралельні виклики (перелік друзів) обмежуються `SemaphoreSlim`.
- **Зберігання ключа API.** Не комітиться в репозиторій; user secrets на розробці, конфігураційний файл поза контролем версій на збірці.
